
# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a menu-driven Python program that provides three useful tools to help users with everyday activities.

## Features

### 1. Simple Calculator
- Performs addition.
- Performs subtraction.
- Performs multiplication.
- Performs division.
- Handles division by zero.

### 2. Shopping List
- Add shopping items.
- View all shopping items.
- Manage a shopping list while the program is running.

### 3. Study Task Manager
- Add study tasks.
- View saved study tasks.
- Organize study activities.

## Python Concepts Used

- Variables
- Input and output
- Conditional statements (if, elif, else)
- While loops
- For loops
- Lists
- Functions
- F-strings
- Comments

## How to Run the Program

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python toolkit.py
```

6. Follow the menu instructions to use the tools.

## Testing

The program was tested to check:
- Calculator operations.
- Adding and viewing shopping items.
- Adding and viewing study tasks.
- Invalid menu choices.
- Returning to the main menu.
- Exiting the program.

Screenshots of the program running are included in the screenshots folder.

## Reflection

Building this Personal Mini-Toolkit helped me understand how different Python concepts work together. The most challenging part was creating the menu loop and making sure users could return to the main menu after using each tool. Testing the different menu choices also helped me understand how to handle invalid inputs. I learned how to use lists to store shopping items and study tasks while the program runs. I also improved my understanding of conditional statements, loops, functions, and f-strings. With one more week, I would add features such as deleting shopping items, marking study tasks as completed, and saving information permanently in a file. Overall, this project has improved my confidence in writing Python programs.
